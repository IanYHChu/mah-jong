# mah-jong：等 Claude 的時候，摸兩圈

Claude 在想、在跑測試、在改十幾個檔案的時候，你在做什麼？盯著轉圈圈？

Claude Code 開放了 mods 之後，輸入框上方多了一塊 plugin 可以自由揮灑的空間。`mah-jong` 就把這塊空間變成一張四列高的牌桌，讓你在等模型的空檔跟三家電腦打**台灣 16 張麻將**。Claude 回來了就繼續工作，牌局停在原地等你；吃、碰、槓、胡、補花、輪莊、算台、算錢，該有的都有，而且完全不佔用你跟 Claude 的對話。

打牌完全不消耗 token：牌局全在本機跑，摸牌、出牌、電腦思考都不會呼叫模型。用量撞到上限、等 limit 重置的時候，正好拿來打發時間。

```
南             西 莊           789萬 5筒x3       上家打出 8筒
                               東x4  碰          要吃碰嗎
 1萬 2萬 3萬 4筒 4筒 6筒 7筒 1條 2條 3條 5條 6條 7條 中 中 中   9萬
q:過 w:胡 e:吃67                                 v:河底  東風圈 你:東 莊
```

## 特色

- **真正的台灣 16 張**：5 組面子加 1 對眼、八張花、吃碰槓、暗槓加槓、搶槓胡、截胡
- **會算台**：依常見的 16 張台數表自動計算，門清自摸、平胡、碰碰胡、混一色、大三元、槓上開花、海底撈月……胡牌時逐項列出
- **會算錢**：100 底 20 台，放槍一家付、自摸三家付，莊家與連莊的台只跟莊家算
- **完整的一將**：莊家胡牌或流局就連莊，否則輪莊；莊回到你手上就換風圈，東南西北打一將
- **不笨的電腦**：會算向聽數挑牌、該吃碰才吃碰、能胡一定胡，有人快聽了還會打現物防守
- **看得懂的牌桌**：萬筒條字花各有顏色；對手吃碰槓時在他的位置閃一下；按 `v` 攤開四家河底與累計分數
- **淺色終端機也能玩**：按 `c` 關掉上色，牌改成按鈕（fullscreen 模式下可以用滑鼠點）

## 安裝

需要支援 mods（plugin hooks 模組）的 Claude Code，作者在 2.1.288 上開發與測試。在 Claude Code 裡輸入：

```
/plugin marketplace add IanYHChu/mah-jong
/plugin install mah-jong@mah-jong
```

或在終端機：

```sh
claude plugin marketplace add IanYHChu/mah-jong
claude plugin install mah-jong@mah-jong
```

裝好後開一個新的 session，牌桌就會出現在輸入框上方。

## 怎麼玩

牌桌上的按鍵是字母，先讓牌桌取得焦點：按 `ctrl+x` 再按 `tab`，按 `Esc` 回到輸入框。在 fullscreen 模式（`/tui fullscreen`）下也可以直接用滑鼠點一下牌桌，或點牌選牌；default 模式不支援滑鼠點擊。

| 時機 | 按鍵 |
|---|---|
| 選牌 | `a` 往左、`d` 往右 |
| 出牌 | `q` 打出選中的牌 |
| 自摸 | `w` 胡 |
| 暗槓、加槓 | `e`、`r`…… |
| 別人出牌時 | `q` 過，`w` `e` `r`…… 依序是胡、吃、碰、槓 |
| 一局結束 | `q` 下一局 |
| 隨時 | `v` 展開或收起河底，`c` 開關上色 |

指令：

- `/mj`：隱藏或叫回牌桌（老闆來了的時候）
- `/mj-deal`：重新開一將，分數歸零

## 牌桌怎麼看

- **第一、二列**：左到右是上家、對家、下家，顯示他們吃碰槓攤下的牌與花數（`5筒x3` 是碰、`5筒x4` 是槓、`暗槓` 看不到是哪張）；還沒吃碰前顯示他的風位，莊家標「莊」。最右邊是剛發生的事和輪到誰
- **第三列**：你的手牌，剛摸的牌放在最右邊，選中的牌反白
- **第四列**：可以按的鍵、你攤下的牌和花；右邊是風圈、你的風位、連莊數
- **有人胡牌**：前兩列換成胡牌那家攤開的整副牌、台數與你這局的輸贏，第四列逐項列出台數

## 台數

採一般玩法：花牌只算自己的正花，風牌只算門風與圈風的刻子。

| 台數 | 項目 |
|---|---|
| 1 | 莊家、門清、自摸、獨聽、三元牌、門風、圈風、正花、海底撈月、槓上開花、搶槓胡 |
| 2 | 連 N 拉 N（每連一次 2 台）、平胡、全求、三暗刻、春夏秋冬、梅蘭竹菊 |
| 3 | 門清自摸 |
| 4 | 碰碰胡、混一色、小三元 |
| 5 | 四暗刻 |
| 8 | 清一色、大三元、小四喜、五暗刻、八仙過海 |
| 16 | 大四喜、地胡 |
| 24 | 天胡 |

同一副牌有多種拆法時，取台數最高的拆法。宣告聽牌（聽牌、天聽、地聽）尚未支援。

## 開發

```sh
claude plugin test .       # 跑測試
claude plugin validate .   # 檢查 manifest 與 hooks 模組
```

程式在 `hooks/`：`tiles.ts` 牌的定義與顯示、`hand.ts` 胡牌判斷與向聽數、`score.ts` 台數與計分、`table.ts` 牌局流程與電腦、`register.tsx` 牌桌畫面與按鍵。
